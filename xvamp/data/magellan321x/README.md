# Extract of the Magellan Dataset

Taken from the NASA Planetary Data System, datasets
"MAGELLAN V RSS 5 OCCULTATION PROFILE ABS H2SO4 VOLMIX V1.0" at
<https://pds.nasa.gov/ds-view/pds/viewProfile.jsp?dsid=MGN-V-RSS-5-OCC-PROF-ABS-H2SO4-V1.0>
and
"MAGELLAN V RSS 5 OCCULTATION PROFILE REF TEMP PRES DENS V1.0" at
<https://pds.nasa.gov/ds-view/pds/viewProfile.jsp?dsid=MGN-V-RSS-5-OCC-PROF-RTPD-V1.0>
on 2025-12-04.

The citation which refers to the processing strategy is:
Jenkins, J. M., Steffes, P. G., Hinson, D. P., Twicken, J. D., & Tyler, G. L. (1994).
"Radio Occultation Studies of the Venus Atmosphere with the Magellan Spacecraft:
2. Results from the October 1991 Experiments".
Icarus, 110(1), 79–94.
<https://doi.org/10.1006/icar.1994.1108>

The following files have been downloaded:

- `mgn_abs.dat`
- `mgn_rtpd.dat`

The corresponding annotations in `mgn_abs.lbl` and `mgn_rtpd.lbl` have been
read in order to read the dataset.
